Setup & Installation Guide

Getting started with Glyph

Add Glyph to your Ada project, connect your display over I2C or SPI, and build bare-metal firmware for the RP2040.

Installing Alire and Toolchain

Glyph is built and packaged using Alire, the package manager for Ada. Alire provisions the cross-compiler toolchain (arm-eabi-gnat) and pulls all hardware dependencies (such as rp2040_hal and hal) automatically.

1. Install Alire

Install Alire from your package manager or download it from alire.ada.dev:

# On macOS
brew install alire

# On Debian / Ubuntu
sudo apt install alire

# On Arch Linux
sudo pacman -S alire

Creating a Project

Create a binary project and add Glyph as a dependency:

# Initialize binary workspace
alr init --bin my_display_app
cd my_display_app

# Add dependencies
alr with glyph
alr with hal
alr with rp2040_hal

Building for RP2040

Glyph includes a complete bare-metal RP2040 reference application in example/ featuring both SSD1306 (I2C) and ILI9341 (SPI) displays:

cd example
alr build

# Flash to connected RP2040 in bootloader mode
elf2uf2-rs -d bin/example_main

Flashing Tip: Hold the BOOTSEL button on your RP2040 board while connecting USB. It will mount as a mass-storage drive, and elf2uf2-rs -d will convert the ELF and flash it automatically.

Display Pinout on RP2040

The reference configuration uses the following hardware pins on the RP2040:

Display & ProtocolRP2040 GPIO PinPeripheral Function
SSD1306 (I2C)GP8I2C0 SDA
SSD1306 (I2C)GP9I2C0 SCL
ILI9341 (SPI)GP18SPI0 SCK
ILI9341 (SPI)GP19SPI0 MOSI / TX
ILI9341 (SPI)GP16SPI0 MISO / RX
ILI9341 (SPI)GP17Chip Select (CS)
ILI9341 (SPI)GP20Data / Command (DC)
ILI9341 (SPI)GP21Hardware Reset (RST)

Host Desktop Simulator

For rapid UI development without physical hardware, compile and run the native desktop simulator:

alr exec -- gprbuild -P simulator/simulator.gpr
./simulator/bin/simulator_main
