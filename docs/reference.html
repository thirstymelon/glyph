API Quick Reference

Glyph API reference

Complete signatures and procedures for SSD1306 (OLED), ILI9341 (Color TFT), drawing primitives, and color manipulation routines.

SSD1306 Display API (Glyph.Display.SSD1306)

The SSD1306 driver provides uniform drawing APIs directly on the Display_T object:

Procedure / FunctionSignatureDescription
Create() return Display_TCreates the SSD1306 display instance with its internal framebuffer.
Init(Self : in out Display_T; Bus : access HAL.I2C.I2C_Port'Class)Initializes the physical display over the provided I2C peripheral.
Set_Address(Self : in out Display_T; Address : HAL.I2C.I2C_Address)Sets the target I2C address (defaults to 16#3C#).
Clear(Self : in out Display_T)Clears the display framebuffer to black.
Paint_Pixel(Self : in out Display_T; X, Y : Integer; Color : Monochrome := On)Plots a pixel with automatic boundary clipping.
Paint_Line(Self : in out Display_T; X1, Y1, X2, Y2 : Integer)Bresenham line with fast orthogonal horizontal/vertical bypass.
Paint_Rectangle(Self : in out Display_T; X, Y, Width, Height : Integer)Draws an outlined rectangle frame.
Paint_Filled_Rectangle(Self : in out Display_T; X, Y, Width, Height : Integer)Draws a filled rectangle or progress bar.
Paint_Circle(Self : in out Display_T; Center_X, Center_Y, Radius : Integer)Draws a midpoint circle outline.
Paint_Filled_Circle(Self : in out Display_T; Center_X, Center_Y, Radius : Integer)Draws a solid filled circle.
Paint_Text(Self : in out Display_T; X, Y : Integer; Text : String; Scale : Positive := 1)Renders ASCII strings using the built-in 5x7 font.
Render(Self : in out Display_T; Force : Boolean := False)Flushes the internal buffer to the physical OLED panel over I2C.

Procedure / FunctionSignatureDescription
Create() return Display_TCreates the ILI9341 display instance with direct streaming and tile support.

Clear(Self : in out Display_T; Color : RGB565 := Black)Clears the display to the specified 16-bit color.
Paint_Pixel(Self : in out Display_T; X, Y : Integer; Color : RGB565 := White)Plots a 16-bit color pixel with automatic boundary clipping.
Paint_Line(Self : in out Display_T; X1, Y1, X2, Y2 : Integer; Color : RGB565 := White)Bresenham line with fast orthogonal horizontal/vertical bypass.
Paint_Rectangle(Self : in out Display_T; X, Y, Width, Height : Integer; Color : RGB565 := White)Draws an outlined rectangle frame.
Paint_Filled_Rectangle(Self : in out Display_T; X, Y, Width, Height : Integer; Color : RGB565 := White)Draws a solid filled rectangle with hardware window acceleration.
Paint_Circle(Self : in out Display_T; Center_X, Center_Y, Radius : Integer; Color : RGB565 := White)Draws a midpoint circle outline.
Paint_Filled_Circle(Self : in out Display_T; Center_X, Center_Y, Radius : Integer; Color : RGB565 := White)Draws a solid filled circle.
Paint_Triangle(Self : in out Display_T; X1, Y1, X2, Y2, X3, Y3 : Integer; Color : RGB565)Draws a wireframe 3-point triangle.
Paint_Filled_Triangle(Self : in out Display_T; X1, Y1, X2, Y2, X3, Y3 : Integer; Color : RGB565)Draws a solid filled scanline triangle.

Render_Scene(Self : in out Display_T; Draw : not null access procedure (Disp : in out Display_T))Transparent tile streaming: partitions the screen into 32-line bands automatically.

Geometric Types (Glyph.Types)

package Glyph.Types is
   type Coordinate is range -32_768 .. 32_767;
   type Dimension  is range 0 .. 32_767;
   type Angle      is range 0 .. 360;

   type Point is record
      X, Y : Coordinate;
   end record;

   type Rectangle is record
      X, Y          : Coordinate;
      Width, Height : Dimension;
   end record;

   type Circle is record
      Center : Point;
      Radius : Dimension;
   end record;

   type Hemisphere_Type is (Top, Bottom, Left, Right);
end Glyph.Types;
