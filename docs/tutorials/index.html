Interactive Curriculum

Learn Glyph on real displays.

A progressive, embedded-focused curriculum using SSD1306 (I2C OLED) and ILI9341 (SPI TFT) on the RP2040. Every lesson features working hardware code, step-by-step explanations, and interactive progress tracking.

Embedded Workflow: Follow the code examples in the Beginner Guide. All programs run directly on the Raspberry Pi Pico RP2040 or in the host simulator.

  1. 1. SSD1306 Display Initialization

    Set up RP2040 I2C pins (GP8/GP9), create an SSD1306 display instance, and clear the screen.

  2. 2. Plotting Pixels & Clipping Safety

    Plot individual pixels directly on the OLED with OLED.Paint_Pixel and explore automatic bounds clipping.

  3. 3. Lines & Bresenham Rasterization

    Draw diagonal, horizontal, and vertical lines with OLED.Paint_Line, leveraging fast orthogonal bypass paths.

  4. 4. Rectangles & Progress Meters

    Render outlined and filled rectangles with OLED.Paint_Rectangle and OLED.Paint_Filled_Rectangle.

  5. 5. Circles, Arcs & Gauges

    Draw midpoint circle outlines, filled discs, and curved dial arcs with OLED.Paint_Circle and OLED.Paint_Filled_Circle.

  6. 6. ILI9341 240x320 SPI Color TFT

    Configure RP2040 SPI0 pins, initialize an ILI9341 color display in transparent Tile_Stream mode, and paint with 16-bit RGB565 colors.

  7. 7. Color Shapes & Filled Triangles

    Render geometric triangles and polygons on ILI9341 with TFT.Paint_Triangle and TFT.Paint_Filled_Triangle.

  8. 8. Text & Bitmap Fonts

    Render ASCII text strings on screen with OLED.Paint_Text and TFT.Paint_Text, with custom fonts, scaling, and color overrides.

  9. 9. RP2040 Hardware Timer Animation Loop

    Build a jitter-free 30 FPS animation loop using the RP2040 64-bit hardware timer (RP.Device.Timer).
