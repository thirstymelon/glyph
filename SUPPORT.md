# Support

This document describes the support resources available for Glyph users.

---

## Community support

### GitHub Discussions

Use [GitHub Discussions](https://github.com/glyph-ada/glyph/discussions) for:

- Questions about using Glyph.
- Ideas for new features.
- Showcasing projects built with Glyph.
- General discussion.

### GitHub Issues

Use the [GitHub issue tracker](https://github.com/glyph-ada/glyph/issues) for:

- Bug reports (use the bug report template).
- Feature requests (use the feature request template).
- Confirmed issues that require code changes.

## Reporting bugs

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on effective bug reports.

**Before reporting**, please:

1. Search existing issues to see if the bug has already been reported.
2. Verify you are using a supported version.
3. Include a minimal, reproducible example if possible.

---

## Security vulnerabilities

Report security vulnerabilities privately to maintainers@glyph-ada.io.

See [SECURITY.md](SECURITY.md) for the security policy.

---

## Commercial support

Commercial support is not currently available. Organizations requiring commercial support should contact the maintainers to discuss options.
